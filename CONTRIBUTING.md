# Contribuciones

Este repositorio es mantenido únicamente por el propietario `oprbguitar`.

No se aceptan modificaciones externas, cambios directos no autorizados ni contribuciones de terceros. La publicación se realiza desde la rama `main` mediante GitHub Actions y GitHub Pages.

Si GitHub permite protección de rama según el plan del repositorio, `main` debe restringirse para que solo el propietario pueda aprobar o integrar cambios.
